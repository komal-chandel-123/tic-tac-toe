# Tic Tac Toe 🎮

A simple, browser-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## 🚀 Demo

Open `index1.html` in your browser to play instantly — no installation required.

## 🛠️ Built With

- **HTML** – Game structure and board layout
- **CSS** – Styling and responsive design
- **JavaScript** – Game logic, turn handling, and win detection

## 📂 Project Structure

```
tic-tac-toe/
├── index1.html      # Main HTML file
├── style1.css        # Styling for the game board and UI
└── script1.js        # Game logic (moves, win/draw detection)
```

## ✨ Features

- Two-player mode (X vs O) on the same device
- Real-time win, loss, and draw detection
- Clean, responsive UI that works on desktop and mobile
- Reset/restart option to play again instantly

## 💻 How to Run Locally

1. Clone the repository
   ```bash
   git clone https://github.com/komal-chandel-123/tic-tac-toe.git
   ```
2. Navigate into the project folder
   ```bash
   cd tic-tac-toe
   ```
3. Open `index1.html` in your browser (just double-click the file, or right-click → Open with → your browser)
